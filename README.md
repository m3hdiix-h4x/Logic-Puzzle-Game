# Logic-Puzzle-Game
Un jeu de puzzle logique desktop développé en Java Swing, regroupant 7 mini-jeux interactifs dans une seule application : 🔢 Number Guess · 🃏 Memory Cards · 🔲 Sudoku · 🐍 Snake · ❌ Tic-Tac-Toe · 🔤 Hangman · 🧱 Brick Breaker Le tout avec un système de score global, un timer, et 3 niveaux de difficulté.
